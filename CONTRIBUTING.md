# Contributing to the Dyula Speech Corpora Toolkit 🇧🇫 🇨🇮 🇲🇱

Thank you for being here!

This project is for *everyone* who wants to see the Dyula (Jula) language, and other West African languages like Mooré, represented in speech and language technologies. There are **no strict rules** for contributing! Just a shared mission to advance our languages through open-source collaboration.

Feel free to:
- Suggest **ideas or improvements**
- Open **pull requests**
- Share **scripts, tools, or data**
- Improve **existing code or documentation**

✅ Just make sure your contribution works and has been tested. We trust you!!!

This toolkit is built on [MooreSpeechCorpora](https://github.com/anyantudre/MooreSpeechCorpora) by Alban NYANTUDRE. Fixes that also apply to the original Mooré toolkit are worth proposing upstream too.

Together, let's build something that makes our languages shine in the AI world. 💛
